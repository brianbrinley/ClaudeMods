From a shell command to a pane row and a budget decision

A gate before a change

Only Companion changes are held against a spent budget: creates, pushes, deploys, undeploys, test runs, and changing calls to the Platform API. Reads, pulls and status checks always run.

Warn, ask or refuse

budgetEnforce chooses. warn (the default) only warns; confirm asks you each time (allow once, allow for the session, raise the budget, or stop); block refuses. A refusal tells Claude which budget is spent and not to work around it.

Every command becomes a step

Whatever runs, the dashboard reads the script's output into a step. A command Claude Code moved to the background stays running until its result is in. A refused step shows as blocked under Needs attention.
