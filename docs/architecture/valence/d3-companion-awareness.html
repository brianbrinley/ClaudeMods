Architecture · Companion's docs

How the dashboard stays aware of Companion

Decoupled

The dashboard keeps no copy of Companion's docs. Its index holds pointers: each doc's headings, key words and a fingerprint. A weekly Companion upgrade is picked up on its own, and nothing goes stale.

Aware, cheaply

The index is rebuilt only when a plugin's version changes, and then only the docs whose fingerprint changed. Between upgrades nothing is read until a prompt needs a few sections.

Drift is a person's call

What Claude must ask before each kind of work is the dashboard's own guide, stamped with the version it was written for. When Companion moves on, the Prompt tab says so, and a model drafts edits for you to review. It never changes the guide itself.
