What happens to a prompt you type

Quick first, better second

The rules check every Boomi prompt, with no model call, so a quick upgrade is ready at once. A model then writes a better one in the background and swaps it in, with a few notes on why it changed.

Held, not blocked

In confirm mode (the default) the prompt waits in the Prompt tab: send it as typed, send the upgrade, or edit it. Claude sees nothing until you choose. A suggestion taken with Tab skips all of this.

Never checked twice

What the dashboard sends from the Prompt tab goes in as your own words, unchecked, so it can't loop back. A secret in a prompt is asked about first, unless the checks are off.
