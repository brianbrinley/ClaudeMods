## Platform

web

## Users

Confirmed (2026-10-17): the docs site is for **technical Boomi people**, PSO consultants and architects who evaluate and use the mods in Boomi Companion work, and for **people deciding whether to adopt** the mods. They are technical and read closely; the repository has been shared with very technical people who asked for a detailed explanation of how the mods work, in a visual form, not only READMEs.

Not chosen as an audience: engineers learning to build Claude Code mods in general. They may read the site, but it is not written for them.

## Product Purpose

Claude Mods is a repository of mods for Claude Code: plugins of function hooks that add live panes, status lines, slash commands and tools. Each mod is self-contained. The two live mods work with Boomi Companion: `boomi-runtime` gives a session a temporary Boomi runtime, and `boomi-dashboard` shows what Claude did with Companion, what needs attention, the session's cost and a budget. The docs site publishes each mod's README (the dashboard's is split into six pages), a style page and an Architecture page with five diagrams, with a search box across every heading, so a reader can understand what a mod does and how before installing it.

## Operating Context

- The site is static, built by `site/build.py` from the READMEs with `site/template.html`, `site/assets/` and `brand/valence.css`, and published to GitHub Pages by `.github/workflows/pages.yml` on every merge to `main` that touches the READMEs, `brand/`, `site/` or a mod.
- The repository and the site are public.
- Pages have a Day/Night toggle that sets `data-theme` on `<html>` and is remembered in `localStorage` (`valence-theme`).
- Mermaid diagrams in READMEs render in the browser. The Architecture diagrams are generated by `docs/architecture/build.py` as self-contained HTML pages with inline SVG; the site's Architecture page shows each one's Valence page scaled to the column, opening full size.

## Capabilities and Constraints

- Keep the site static and dependency-free where possible, with its generator in the repository.
- Generated docs must not name customers or engagements.
- Any claim about what a mod does must match the code; what is set aside is said to be set aside (`boomi-standards` is built, set aside, and tracked in `IDEAS.md`).
- Decided: the site doesn't host the Exosphere versions of the diagrams. The Architecture page links to `docs/architecture` on GitHub, where they live with how they're built.
- Open: the diagrams' labels are small (7 to 9px at their designed size, smaller still when scaled to the column). Impeccable's detector flags them. Whether to enlarge them is undecided, because it changes every diagram's geometry.

## Brand Commitments

- The repository's default look is **Valence, Miami Deco** (`brand/tokens.json`): Poiret One for the wordmark and display only, Josefin Sans for headings and labels, system UI sans for body and data. Status uses the fixed status colors, always with an icon and a label, never color alone.
- What a mod produces for Boomi people to read outside Claude Code follows **Boomi's Exosphere** design system instead. Decided 2026-10-17: the standalone architecture files are Exosphere; the docs site's copies are Valence.

## Evidence on Hand

- Five architecture diagrams in two looks each, in `docs/architecture/`, each with three short notes. All checked with the diagram-design skill's own checks and in a browser.
- The mods' READMEs and changelogs, and `IDEAS.md`.
- Absent, and not to be invented: customer names, testimonials, benchmarks, install counts, pricing, licensing claims.

## Product Principles

Derived from the confirmed audience and the repository's own conventions; not separately confirmed.

- Show the mechanism, not the pitch: a technical reader trusts a diagram that matches the code.
- Be plain about what is built, what is set aside, and what is not checked yet.
- The reader decides: nothing here installs, runs or changes anything without their say.
- One source of truth: diagrams and docs are generated or kept next to the code they describe.
